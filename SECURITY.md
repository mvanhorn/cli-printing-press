# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Report vulnerabilities through GitHub private vulnerability reporting. Use the **Report a vulnerability** button on this repository's [Security](https://github.com/mvanhorn/cli-printing-press/security) tab, or open a report at <https://github.com/mvanhorn/cli-printing-press/security/advisories/new>.

Do not open a public issue for a vulnerability.

## Scope

In scope: the Printing Press generator, including template defects that ship into printed CLIs, and the CLIs and MCP servers it generates.

CLIs in [mvanhorn/printing-press-library](https://github.com/mvanhorn/printing-press-library) are refreshed after a Printing Press security fix.

Fixes are announced in the release notes or in a [GitHub Security Advisory](https://github.com/mvanhorn/cli-printing-press/security/advisories) that names the first fixed version. Reporters are credited in the advisory by their GitHub username.
