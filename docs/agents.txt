## Part A — Install the single `pp` binary (zero Go required)

1. Install `pp` to `~/.local/bin/pp`:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/mvanhorn/cli-printing-press/main/scripts/install-pp.sh | sh
   ```

   Ensure `~/.local/bin` is on `PATH`, then verify:

   ```bash
   pp --version
   ```

2. Smoke-test a zero-auth starter cartridge (~150ms, ~140 tokens, no browser):

   ```bash
   pp route https://www.espn.com/nba/scoreboard --json
   pp run espn scoreboard --compact --limit 5 --json
   ```

3. Seed your private local Personal Life Lake (`~/.pp/lake.db`):

   ```bash
   pp lake sync espn hackernews
   pp lake stats --json
   ```

4. Run the Verified Local Trust Shield audit:

   ```bash
   pp audit --json
   ```

## Part B — Connect the lean 5-tool local MCP server (optional, ~650 tokens total)

For MCP hosts (Claude Desktop, Cowork, Cursor, OpenClaw, Hermes, Windsurf):

```json
{
  "mcpServers": {
    "printing-press": {
      "command": "pp",
      "args": ["mcp"]
    }
  }
}
```

This single stdio server exposes 5 progressive-discovery tools (`pp_route`, `pp_discover`, `pp_run`, `pp_lake_search`, `pp_lake_sql`) covering all 616+ Printing Press apps and your local Life Lake — with zero remote MCP server and zero tool-mutation rug-pull risk.

## Part C — Wire into Ardia Browser (optional, macOS)

If `/Applications/Ardia.app` is installed, print and install the Printing Press Ardia plugin + omnibox hook:

```bash
pp ardia setup
```

Then enable the plugin in Ardia > Settings > Plugins.

## Part D — Standing Agent Routing Rule ("Skip Pixels on Repeat Work")

Save these rules in your agent's persistent instructions:

1. Before opening a browser tab (`ardia browse`, `browse`, or computer-use) for a known consumer site, SaaS app, or repeat lookup, check the fast path first:
   `pp route <url-or-app> --json`
2. If `matched: true` and installed, run `pp run <app> <cmd> --compact --json` (or the installed `<app>-pp-cli` binary). Typical win: ~150ms and ~150 tokens instead of 4-70 seconds and 12,000-50,000 tokens.
3. If `matched: true` and not yet installed, install with zero Go compilation via `pp use <app>` (downloads checksum-verified prebuilt binary or signed cartridge in <2s).
4. If `matched: false` and the user will run this workflow more than once, compile it once from a real browser session:
   `pp record --backend ardia <url>` (or `pp record --from-har <capture.har>`)
   Every subsequent run skips the browser forever.
5. For cross-app personal questions, query the local Life Lake first:
   `pp lake search "<query>" --json` or `pp lake sql "SELECT ..."` (read-only, ~5ms, zero cloud).
6. If a previously working cartridge fails with HTTP 404/410 or schema extraction drift, run `pp heal <app> <cmd>` instead of falling back to brittle pixel clicking.
